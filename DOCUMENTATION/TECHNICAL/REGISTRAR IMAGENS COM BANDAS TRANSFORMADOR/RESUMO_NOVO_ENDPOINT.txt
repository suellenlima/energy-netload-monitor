✅ NOVO ENDPOINT: Registrar Imagem com 5 Bandas para Transformador

═══════════════════════════════════════════════════════════════════════════════

📝 ENDPOINT CRIADO:

  POST /satelite/v2/transformador/{transformador_id}/registrar-imagem

═══════════════════════════════════════════════════════════════════════════════

🔄 COMPARAÇÃO ANTES vs DEPOIS:

  ANTES (endpoints existentes)
  ─────────────────────────────
  └─ GET /satelite/v2/transformador/{id}/imagens
     • Busca imagens no CBERS-4A ✅
     • Apenas lista, não salva ❌
     • Sem bandas persistidas ❌
  
  └─ POST /satelite/subestacao/{id}/registrar-imagem
     • Salva 1 URL apenas ❌
     • Sem suporte a 5 bandas ❌
     • Sem endpoint para transformador ❌

  DEPOIS (novo endpoint)
  ───────────────────────
  └─ POST /satelite/v2/transformador/{id}/registrar-imagem ✨ NOVO
     • Salva metadados ✅
     • Salva todas as 5 bandas ✅
     • Uma chamada faz tudo ✅
     • Para transformador ✅

🔗 FLUXO COMPLETO DE USO:

  1. GET /satelite/v2/transformador/{id}/imagens
     └─ Busca imagens no CBERS-4A → retorna URLs das 5 bandas

  2. POST /satelite/v2/transformador/{id}/registrar-imagem ✨ NOVO
     └─ Salva as 5 bandas no banco → retorna imagem_id

  3. POST /telhados/transformador/detectar-telhados
     └─ Processa com ImagemMultibandaLoader
     └─ Retorna: rgb_multiespectral, clahe_aplicado, ndvi_filtro_aplicado
