# 🛰️ Serviço de Imagens de Satélite - README

## Visão Geral Rápida

Este serviço permite detectar as coordenadas e área de uma subestação, e consultar imagens de satélite de alta resolução via APIs públicas como INPE, Sentinel-2 e Landsat.

## ⚡ Quick Start

### 1. Iniciar o Backend

```bash
cd backend
pip install -r requirements.txt
uvicorn src.main:app --reload
```

### 2. Obter Coordenadas de uma Subestação

```bash
curl "http://localhost:8000/satelite/subestacao/1/coordenadas?raio_km=5.0"
```

### 3. Consultar Imagens Disponíveis

```bash
curl -X POST "http://localhost:8000/satelite/consultar-disponibilidade" \
  -H "Content-Type: application/json" \
  -d '{
    "subestacao_id": 1,
    "sensores": ["Sentinel-2", "Landsat"]
  }'
```

## 📡 Endpoints Principais

| Endpoint | Método | Descrição |
|----------|--------|-----------|
| `/satelite/subestacao/{id}/coordenadas` | GET | Coordenadas + bbox |
| `/satelite/bbox/{id}` | GET | Apenas bbox |
| `/satelite/consultar-disponibilidade` | POST | URLs de imagens |
| `/satelite/subestacao/{id}/imagens` | GET | Histórico registrado |
| `/satelite/subestacao/{id}/registrar-imagem` | POST | Registrar nova imagem |

## 🔗 Integrações

### Plataformas STAC
- **Sentinel-2**: Planetary Computer (Microsoft)
- **Landsat**: USGS Earth Explorer

### INPE / Terrabrasilis
- **WMS**: Serviço web de mapeamento
- **Camadas**: PRODES, DETER, Alertas

## 📝 Exemplo Completo

```python
import requests
from datetime import datetime, timedelta

# 1. Obter bbox
response = requests.get(
    "http://localhost:8000/satelite/subestacao/1/coordenadas"
)
dados = response.json()
print(f"Área: {dados['bbox']['dimensoes']}")

# 2. Consultar imagens
response = requests.post(
    "http://localhost:8000/satelite/consultar-disponibilidade",
    json={
        "subestacao_id": 1,
        "data_inicio": (datetime.now() - timedelta(days=30)).isoformat(),
        "data_fim": datetime.now().isoformat()
    }
)
print(f"Imagens disponíveis: {response.json()['urls_consulta']}")

# 3. Registrar imagem
requests.post(
    "http://localhost:8000/satelite/subestacao/1/registrar-imagem",
    json={
        "sensor": "Sentinel-2",
        "data_aquisicao": datetime.now().isoformat(),
        "resolucao_m": 10,
        "cobertura_nuvem_pct": 12.5,
        "url": "https://..."
    }
)
```
