## Componentes Principais

### 1. **BoundingBox** (Classe de Dados)
```python
@dataclass
class BoundingBox:
    min_lat: float
    max_lat: float
    min_lon: float
    max_lon: float
    
    # Propriedades calculadas
    @property
    def center_lat() -> float
    @property
    def center_lon() -> float
    @property
    def width_km() -> float
    @property
    def height_km() -> float
    
    # Métodos de conversão
    def to_wgs84_string() -> str
    def to_geojson() -> Dict
```

**Uso Interno**: Cálculos de áreas geográficas
**Conversão**: WGS84 ↔ GeoJSON ↔ STAC bbox

---

### 2. **SatelliteMetadata** (Dataclass)
```python
@dataclass
class SatelliteMetadata:
    id: str
    data_aquisicao: datetime
    sensor: str
    resolucao_m: int
    cobertura_nuvem_pct: float
    url: str
    bounding_box: BoundingBox
    propriedades: Dict
```

**Mapeamento BD**: → `satelite_imagens` table

---

### 3. **INPESatelliteService** (Classe Principal)

#### Métodos Públicos:

**`calcular_bbox_subestacao(lat, lon, raio_km=5.0) → BoundingBox`**
- Entrada: Coordenadas da subestação
- Processo: Conversão graus → km usando trigonometria
- Saída: BoundingBox calculada
- **Nota**: Usa aproximação simplificada, adequada para raios < 50 km

**`construir_url_wms_terrabrasilis(bbox, camada, ...) → str`**
- Entrada: BBox, nome da camada (prodes, deter, alerts)
- Processo: Montagem de query parameters WMS
- Saída: URL completa para GET
- **Base**: `https://terrabrasilis.dpi.inpe.br/geoserver/ows`

**`gerar_url_sentinel2_stac(bbox, data_inicio, data_fim, ...) → Dict`**
- Entrada: BBox e período temporal
- Processo: Construção de payload STAC
- Saída: URL e payload POST
- **API**: Planetary Computer (Microsoft)
- **Coleção**: `sentinel-2-l2a`
- **Filtros**: Cloud cover ≤ 50% (customizável)

**`gerar_url_landsat_stac(bbox, data_inicio, data_fim, ...) → Dict`**
- Entrada: BBox e período temporal
- Processo: Construção de payload STAC Landsat
- Saída: URL e payload POST
- **API**: USGS (rstac.cr.usgs.gov)
- **Coleção**: `landsat-c2-l2`

**`consultar_subestacao_satellite_data(engine, sub_id, ...) → Dict`**
- **Orquestração completa**:
  1. Busca subestação no BD
  2. Calcula BBox
  3. Gera URLs para 3 fontes
  4. Retorna consolidado
- **Cache**: Não implementado (futuro)

**`armazenar_metadata_imagem(engine, sub_id, metadata) → bool`**
- Cria tabela se não existir
- INSERT em `satelite_imagens`
- Constraints: Chave primária composta (sub_id, sensor, data)
- **Automático**: Trigger para atualizar stats

**`listar_imagens_subestacao(engine, sub_id, ...) → List[Dict]`**
- Query simples com ordenação
- TTL/cache: Não configurado
- **Índice**: `idx_satelite_imagens_composite`

## Endpoints REST

### 1. GET `/satelite/subestacao/{id}/coordenadas`

**Parâmetros**:
- `id` (path): ID da subestação
- `raio_km` (query, default=5.0): Raio de cobertura

**Fluxo**:
```
1. Validar ID
2. Buscar no BD (subestacoes_detectadas)
3. Calcular BBox
4. Gerar URLs (STAC + WMS)
5. Retornar DadosSatelliteSubestacao
```

**Resposta** (200):
```json
{
    "subestacao": {...},
    "bbox": {...},
    "periodo": {...},
    "urls_consulta": {...}
}
```

**Erros**:
- 404: Subestação não encontrada
- 500: Erro no servidor

---

### 2. GET `/satelite/bbox/{id}`

**Variação simplificada** de `/coordenadas`
- Retorna apenas `BoundingBoxModel`
- Mais leve se só precisa de bbox

---

### 3. POST `/satelite/consultar-disponibilidade`

**Body**:
```json
{
    "subestacao_id": 1,
    "data_inicio": "2025-12-01T00:00:00",
    "data_fim": "2026-01-29T23:59:59",
    "raio_km": 5.0,
    "sensores": ["Sentinel-2", "Landsat"]
}
```

**Validações** (Pydantic):
- `subestacao_id`: int > 0
- `data_inicio` < `data_fim`
- `raio_km`: 0.5 ≤ raio ≤ 50.0
- `sensores`: Subset de ["Sentinel-2", "Landsat"]

**Resposta**: `DadosSatelliteSubestacao`

---

### 4. GET `/satelite/subestacao/{id}/imagens`

**Parâmetros**:
- `id` (path): ID da subestação
- `limite` (query, default=50): Max registros
- `ordenar_por` (query, default="data_aquisicao"): Campo

**Query**:
```sql
SELECT * FROM satelite_imagens
WHERE subestacao_id = :id
ORDER BY {campo} DESC
LIMIT :limite
```

**Índices usados**:
- `idx_satelite_imagens_composite` (subestacao_id, data_aquisicao DESC)

---

### 5. POST `/satelite/subestacao/{id}/registrar-imagem`

**Body**:
```json
{
    "sensor": "Sentinel-2",
    "data_aquisicao": "2026-01-15T13:12:41",
    "resolucao_m": 10,
    "cobertura_nuvem_pct": 12.5,
    "url": "https://...",
    "propriedades": {...}
}
```

**Processo**:
1. Criar tabela (idempotente)
2. Construir `SatelliteMetadata`
3. INSERT com UPSERT (ON CONFLICT)
4. Trigger atualiza stats automaticamente

## Banco de Dados

### Tabela: `satelite_imagens`

```sql
CREATE TABLE satelite_imagens (
    id SERIAL PRIMARY KEY,
    subestacao_id INTEGER NOT NULL,  -- FK
    sensor VARCHAR(50) NOT NULL,
    data_aquisicao TIMESTAMPTZ NOT NULL,
    resolucao_m INTEGER,
    cobertura_nuvem_pct FLOAT (0-100),
    url TEXT,
    bbox_json JSONB,
    propriedades_json JSONB,
    data_registro TIMESTAMPTZ,
    CONSTRAINT unique (sub_id, sensor, data)
);
```

**Índices** (7 total):
```
- PRIMARY KEY: id
- idx_satelite_imagens_subestacao (sub_id)
- idx_satelite_imagens_data (data DESC)
- idx_satelite_imagens_sensor (sensor)
- idx_satelite_imagens_nuvem (nuvem_pct)
- idx_satelite_imagens_composite (sub_id, data DESC)
```

**Trigger**:
- `trigger_satelite_stats` → Atualiza stats mensais

---

### Tabela: `satelite_cache_stac`

```sql
CREATE TABLE satelite_cache_stac (
    id BIGSERIAL PRIMARY KEY,
    bbox_hash VARCHAR(64) NOT NULL,  -- SHA256(bbox)
    min_lat, max_lat, min_lon, max_lon,
    data_inicio, data_fim,
    sensor VARCHAR(50),
    resultado_json JSONB,
    data_cache TIMESTAMPTZ,
    validade_ate TIMESTAMPTZ,  -- TTL
    CONSTRAINT unique (bbox_hash, sensor, data_inicio, data_fim)
);
```

**Propósito**: Evitar requisições repetidas ao STAC
**TTL**: Configurável (padrão: 7 dias)

---

### Tabela: `satelite_cobertura_stats`

```sql
CREATE TABLE satelite_cobertura_stats (
    id SERIAL PRIMARY KEY,
    subestacao_id INTEGER,
    sensor VARCHAR(50),
    mes_ano DATE,  -- 2026-01-01
    media_nuvem_pct FLOAT,
    total_cenas INTEGER,
    cenas_baixa_nuvem INTEGER,  -- < 20% cloud
    data_atualizacao TIMESTAMPTZ,
    CONSTRAINT unique (sub_id, sensor, mes_ano)
);
```

**Atualização**: Via trigger (automática)

## Integração com APIs Externas

### 1. Terrabrasilis WMS (INPE)

**Base URL**: `https://terrabrasilis.dpi.inpe.br/geoserver/ows`

**Query Parameters**:
```
service=WMS
version=1.1.0
request=GetMap
layers=prodes  (ou deter, alerts, ...)
bbox=min_lon,min_lat,max_lon,max_lat
width=512
height=512
srs=EPSG:4326
format=image/geotiff (ou image/png)
```

**Resposta**: Arquivo GeoTIFF ou PNG
**Rate Limit**: Nenhum conhecido
**Autenticação**: Nenhuma

---

### 2. Sentinel-2 STAC (Planetary Computer)

**Base URL**: `https://planetarycomputer.microsoft.com/api/stac/v1`

**Endpoint**: `/search` (POST)

**Payload**:
```json
{
    "bbox": [min_lon, min_lat, max_lon, max_lat],
    "datetime": "2026-01-01T00:00:00Z/2026-01-31T23:59:59Z",
    "collections": ["sentinel-2-l2a"],
    "query": {
        "eo:cloud_cover": {"lte": 50}
    },
    "limit": 10
}
```

**Resposta**: GeoJSON FeatureCollection
**Features**: 
- ID STAC único
- Propriedades (data, tile MGRS, cloud cover)
- Assets (B02-B12, TCI, SCL, etc.)
- Links (HTTP para download)

---

### 3. Landsat STAC (USGS)

**Base URL**: `https://rstac.cr.usgs.gov`

**Endpoint**: `/collections/landsat-c2-l2/items`

**Payload**: Similar a Sentinel-2
```json
{
    "bbox": [...],
    "datetime": "...",
    "query": {
        "landsat:cloud_cover": {"lte": 50}
    },
    "limit": 10
}
```

**Diferenças vs Sentinel-2**:
- Resolução: 30m (vs 10-60m)
- Bandas: 11 (vs 12)
- Órbita: 8 dias (vs 5 dias)

## Performance

### Query Optimization

**Consulta típica** (listar imagens):
```sql
SELECT * FROM satelite_imagens
WHERE subestacao_id = 1
ORDER BY data_aquisicao DESC
LIMIT 50;
```

**Índice usado**: `idx_satelite_imagens_composite`
**Execution time**: ~1-5ms (com 10k registros)

### Caching Estratégias

1. **BD Cache**: `satelite_cache_stac` (7 dias TTL)
2. **API Response**: Pydantic models em memória (session)
3. **HTTP Cache**: Accept headers não implementado

### Bottlenecks Identificados

⚠️ **STAC API Latency**: 5-20 segundos
- **Solução**: Implementar async requests
- **Implementação futura**: aiohttp + asyncio

⚠️ **Requisições WMS**: Dependente da resolução
- **Solução**: Limitar a `512x512 pixels`
