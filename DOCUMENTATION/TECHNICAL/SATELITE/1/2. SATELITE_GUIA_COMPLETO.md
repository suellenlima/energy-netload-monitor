# 🛰️ Serviço de Imagens de Satélite - Guia de Uso

## 📋 Visão Geral

Este guia descreve como usar o novo serviço integrado de imagens de satélite para consultar, registrar e gerenciar dados de satélite (Sentinel-2, Landsat, etc.) de áreas de subestações através de APIs do **INPE**, **STAC** e outras plataformas.

## 🎯 Funcionalidades Principais

### 1. **Detectar Coordenadas da Área de Subestação**
- Obter latitude, longitude e bounding box de uma subestação
- Calcular área de cobertura em torno da subestação
- Retornar dimensões aproximadas (largura e altura em km)

### 2. **Consultar Disponibilidade de Imagens**
- Verificar quais imagens de satélite estão disponíveis
- Suporte a Sentinel-2, Landsat 8/9 e produtos INPE
- Filtrar por período, cobertura de nuvem e sensor

### 3. **Obter URLs de Imagens**
- **STAC**: Padrão OGC para metadados de imagens geoespaciais
- **WMS**: Serviços web de mapeamento INPE/Terrabrasilis
- **APIs públicas**: Acesso direto a acervos de satélites

### 4. **Registrar Imagens no Banco**
- Armazenar metadados de imagens processadas
- Rastrear histórico de imagens por subestação
- Gerenciar metadados customizados

#### Endpoint

### 2️⃣ Consultar Disponibilidade de Imagens

#### Endpoint
```bash
POST /satelite/consultar-disponibilidade
```

#### Exemplo com Python
```python
import requests
from datetime import datetime, timedelta

consulta = {
    "subestacao_id": 1,
    "data_inicio": (datetime.now() - timedelta(days=30)).isoformat(),
    "data_fim": datetime.now().isoformat(),
    "raio_km": 5.0,
    "sensores": ["Sentinel-2", "Landsat"]
}

response = requests.post(
    "http://localhost:8000/satelite/consultar-disponibilidade",
    json=consulta
)

dados = response.json()

# Sentinel-2 STAC
if "sentinel2" in dados["urls_consulta"]:
    s2_url = dados["urls_consulta"]["sentinel2"]["url"]
    print(f"STAC Sentinel-2: {s2_url}")
    print(f"Payload: {dados['urls_consulta']['sentinel2']['payload']}")

# Landsat STAC  
if "landsat" in dados["urls_consulta"]:
    l8_url = dados["urls_consulta"]["landsat"]["url"]
    print(f"STAC Landsat: {l8_url}")

# WMS Terrabrasilis
if "terrabrasilis_wms" in dados["urls_consulta"]:
    wms_url = dados["urls_consulta"]["terrabrasilis_wms"]["url"]
    print(f"WMS Terrabrasilis: {wms_url}")
    print(f"Camadas: {dados['urls_consulta']['terrabrasilis_wms']['camadas_disponiveis']}")
```

### 3️⃣ Buscar Imagens no STAC (Sentinel-2 / Landsat)

#### Exemplo Completo com Requests Python

```python
import requests
import json

# 1. Obter URL STAC da subestação
subestacao_response = requests.post(
    "http://localhost:8000/satelite/consultar-disponibilidade",
    json={
        "subestacao_id": 1,
        "sensores": ["Sentinel-2"]
    }
)

dados = subestacao_response.json()
stac_config = dados["urls_consulta"]["sentinel2"]

# 2. Fazer busca STAC
response = requests.post(
    stac_config["url"],
    json=stac_config["payload"],
    headers={"Content-Type": "application/json"}
)

items = response.json()

# 3. Processar resultados
print(f"Total de cenas encontradas: {len(items.get('features', []))}")

for feature in items.get("features", [])[:5]:  # Primeiras 5
    props = feature["properties"]
    assets = feature["assets"]
    
    print(f"\nCena: {feature['id']}")
    print(f"Data: {props['datetime']}")
    print(f"Cobertura de nuvem: {props['eo:cloud_cover']}%")
    
    # Link para TCI (True Color Image)
    if "TCI_10m" in assets:
        print(f"URL imagem: {assets['TCI_10m']['href']}")
```

### 4️⃣ Buscar Imagens via WMS (Terrabrasilis INPE)

```python
    print(f"Erro: {response.status_code}")
    print(response.text)
```

### 5️⃣ Registrar Imagem no Banco de Dados

#### Endpoint
```bash
POST /satelite/subestacao/{subestacao_id}/registrar-imagem
```

#### Exemplo com Python

```python
import requests
from datetime import datetime

imagem_data = {
    "sensor": "Sentinel-2",
    "data_aquisicao": datetime.now().isoformat(),
    "resolucao_m": 10,  # Sentinel-2 tem resolução de 10-60m
    "cobertura_nuvem_pct": 12.5,
    "url": "https://example.com/S2A_MSIL2A_20260101T131241_N0500_R031_T23KPA.zip",
    "propriedades": {
        "tile": "23KPA",
        "nivel_processamento": "L2A",
        "missao": "Copernicus"
    }
}

response = requests.post(
    "http://localhost:8000/satelite/subestacao/1/registrar-imagem",
    json=imagem_data
)

resultado = response.json()
print(f"Status: {resultado['status']}")
print(f"Mensagem: {resultado['mensagem']}")
print(f"ID da imagem: {resultado['imagem_id']}")
```

### 6️⃣ Listar Imagens Registradas

#### Endpoint
```bash
GET /satelite/subestacao/{subestacao_id}/imagens?limite=50&ordenar_por=data_aquisicao
```

#### Exemplo com Python

```python
import requests

response = requests.get(
    "http://localhost:8000/satelite/subestacao/1/imagens",
    params={"limite": 50, "ordenar_por": "data_aquisicao"}
)

dados = response.json()

print(f"Total de imagens: {dados['total_imagens']}")
for imagem in dados['imagens']:
    print(f"\n{imagem['sensor']} - {imagem['data_aquisicao']}")
    print(f"  Resolução: {imagem['resolucao_m']}m")
    print(f"  Nuvem: {imagem['cobertura_nuvem_pct']}%")
    print(f"  URL: {imagem['url']}")
```

## 🔌 Endpoints Disponíveis

| Método | Endpoint | Descrição |
|--------|----------|-----------|
| `GET` | `/satelite/subestacao/{id}/coordenadas` | Obter coordenadas e bbox |
| `GET` | `/satelite/bbox/{id}` | Obter apenas a bbox |
| `POST` | `/satelite/consultar-disponibilidade` | Consultar imagens STAC/WMS |
| `GET` | `/satelite/subestacao/{id}/imagens` | Listar imagens registradas |
| `POST` | `/satelite/subestacao/{id}/registrar-imagem` | Registrar nova imagem |

## 📊 Caso de Uso Completo

```python
"""
Fluxo completo: Detectar subestação → Obter bbox → 
Consultar imagens → Registrar no banco
"""

import requests
from datetime import datetime, timedelta

# 1. DETECTAR SUBESTAÇÃO E OBTER BBOX
print("1. Buscando subestação...")
sub_response = requests.get(
    "http://localhost:8000/satelite/subestacao/1/coordenadas",
    params={"raio_km": 10.0}
)
subestacao = sub_response.json()
bbox = subestacao["bbox"]

print(f"Subestação: {subestacao['subestacao']['nome']}")
print(f"Área: {bbox['dimensoes']['largura_km']:.1f} km × {bbox['dimensoes']['altura_km']:.1f} km")

# 2. CONSULTAR DISPONIBILIDADE DE IMAGENS
print("\n2. Consultando disponibilidade de imagens...")
consulta_response = requests.post(
    "http://localhost:8000/satelite/consultar-disponibilidade",
    json={
        "subestacao_id": 1,
        "data_inicio": (datetime.now() - timedelta(days=90)).isoformat(),
        "data_fim": datetime.now().isoformat(),
        "sensores": ["Sentinel-2", "Landsat"]
    }
)
urls = consulta_response.json()

# 3. BUSCAR NO STAC SENTINEL-2
print("\n3. Buscando Sentinel-2...")
s2_config = urls["urls_consulta"]["sentinel2"]
stac_response = requests.post(
    s2_config["url"],
    json=s2_config["payload"]
)
items = stac_response.json()

print(f"Encontradas {len(items.get('features', []))} cenas")

# 4. REGISTRAR PRIMEIRA IMAGEM DISPONÍVEL
if items.get("features"):
    first_item = items["features"][0]
    
    print("\n4. Registrando primeira imagem...")
    props = first_item["properties"]
    
    register_response = requests.post(
        "http://localhost:8000/satelite/subestacao/1/registrar-imagem",
        json={
            "sensor": "Sentinel-2",
            "data_aquisicao": props["datetime"],
            "resolucao_m": 10,
            "cobertura_nuvem_pct": props.get("eo:cloud_cover", 0),
            "url": first_item.get("id", ""),
            "propriedades": {
                "stac_id": first_item["id"],
                "tile": props.get("s2:mgrs_tile", ""),
            }
        }
    )
    
    resultado = register_response.json()
    print(f"Resultado: {resultado['status']}")

# 5. LISTAR TODAS AS IMAGENS REGISTRADAS
print("\n5. Listando imagens armazenadas...")
list_response = requests.get(
    "http://localhost:8000/satelite/subestacao/1/imagens"
)
imagens = list_response.json()

print(f"Total registradas: {imagens['total_imagens']}")
for img in imagens['imagens'][:3]:
    print(f"  - {img['sensor']} | {img['data_aquisicao']} | {img['cobertura_nuvem_pct']}% nuvem")
```

## 🐛 Troubleshooting

### Erro: "Subestação não encontrada"
- Verifique se o ID da subestação existe no banco
- Execute `GET /subestacoes/detectadas` para listar IDs

### Erro: Sem imagens disponíveis
- Aumente o período de data
- Reduza o filtro de cobertura de nuvem
- Verifique se as coordenadas estão corretas

### Erro: Timeout em consulta STAC
- As APIs STAC podem ser lentas (~10-20s)
- Considere implementar cache em sua aplicação
- Use períodos menores (dias em vez de meses)

## 📝 Notas Importantes

1. **STAC é uma API aberta** - Qualquer pessoa pode consultá-la sem autenticação
2. **WMS Terrabrasilis usa dados INPE** - Atualizado diariamente
3. **Imagens geoespaciais são grandes** - Considere implementar download assíncrono
4. **Cobertura de nuvem varia** - Regiões tropicais têm maior nebulosidade
5. **Resoluções variam** - Sentinel-2: 10-60m | Landsat: 30m
