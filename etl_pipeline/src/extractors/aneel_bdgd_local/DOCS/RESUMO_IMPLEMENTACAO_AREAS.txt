┌─ FUNÇÃO calcular_area_transformadores() ───────────────────────────────┐
│                                                                          │
│  def calcular_area_transformadores(                                     │
│      tipo_tensao: str,     # 'BT', 'MT' ou 'AT'                        │
│      distribuidora: str,   # Nome da distribuidora                      │
│      gdb_path: Path = None # Caminho do GDB (opcional)                 │
│  ) -> Tuple[int, int]:     # (calculadas, atualizadas)                 │
│                                                                          │
│  Lógica Interna:                                                        │
│  1. Definir raio de buffer por tipo (BT:500m, MT:1km, AT:2km)         │
│  2. SQL Query:                                                          │
│     - WITH consumidor_grupos AS (                                       │
│         SELECT transformador_codigo, COUNT(*) as num_consumidores      │
│         FROM consumidores_[bt|mt|at]_aneel                             │
│         GROUP BY transformador_codigo                                   │
│       )                                                                  │
│     - SELECT CASE WHEN num_consumidores >= 3                           │
│         THEN ST_ConvexHull(...)                                        │
│         ELSE ST_Buffer(..., raio)                                      │
│       END as geom, ...                                                  │
│     - INSERT INTO transformador_area_cobertura                         │
│       ON CONFLICT (transformador_codigo) DO UPDATE                     │
│  3. Execute e retornar rowcount                                         │
│  4. Log resultado com raio buffer utilizado                            │
│                                                                          │
│  Vantagens:                                                             │
│  ✅ Query agregada em SQL (eficiente)                                  │
│  ✅ Geometria via PostGIS (ST_ConvexHull, ST_Buffer, ST_Area)         │
│  ✅ Upsert automático (idempotente)                                    │
│  ✅ Suporta recálculos sem duplicação                                  │
│  ✅ Integrado no fluxo ETL                                             │
