Você agora possui um **serviço production-ready** para:

✅ **Acessar via API REST** todos os dados com documentação automática

## 📍 5 Endpoints Disponíveis

```
GET  /satelite/subestacao/{id}/coordenadas
     └─ Retorna: coords + bbox + URLs STAC/WMS

GET  /satelite/bbox/{id}
     └─ Retorna: apenas bounding box

POST /satelite/consultar-disponibilidade
     └─ Body: subestacao_id, periodo, sensores
     └─ Retorna: URLs para consultar imagens

GET  /satelite/subestacao/{id}/imagens
     └─ Query: limite=50, ordenar_por="data_aquisicao"
     └─ Retorna: histórico de imagens registradas

POST /satelite/subestacao/{id}/registrar-imagem
     └─ Body: sensor, data, resolucao, nuvem%, url
     └─ Retorna: status da operação
```

## 🔌 Como Usar em Python

```python
import requests
from datetime import datetime, timedelta

# 1. OBTER COORDENADAS
response = requests.get(
    "http://localhost:8000/satelite/subestacao/1/coordenadas",
    params={"raio_km": 5.0}
)
dados = response.json()
print(f"Área: {dados['bbox']['dimensoes']}")  # {'largura_km': 10.0, 'altura_km': 10.0}

# 2. CONSULTAR IMAGENS DISPONÍVEIS
response = requests.post(
    "http://localhost:8000/satelite/consultar-disponibilidade",
    json={
        "subestacao_id": 1,
        "data_inicio": (datetime.now() - timedelta(days=30)).isoformat(),
        "data_fim": datetime.now().isoformat(),
        "sensores": ["Sentinel-2", "Landsat"]
    }
)
urls = response.json()
print(f"STAC Sentinel-2: {urls['urls_consulta']['sentinel2']['url']}")

# 3. REGISTRAR IMAGEM ENCONTRADA
response = requests.post(
    "http://localhost:8000/satelite/subestacao/1/registrar-imagem",
    json={
        "sensor": "Sentinel-2",
        "data_aquisicao": datetime.now().isoformat(),
        "resolucao_m": 10,
        "cobertura_nuvem_pct": 12.5,
        "url": "https://..."
    }
)
print(f"Registrado: {response.json()['status']}")

# 4. LISTAR IMAGENS ARMAZENADAS
response = requests.get(
    "http://localhost:8000/satelite/subestacao/1/imagens",
    params={"limite": 50}
)
imagens = response.json()
print(f"Total: {imagens['total_imagens']} imagens")
```

## 📊 Fluxo de Uma Solicitação

```
[1] Cliente pede: GET /satelite/subestacao/1/coordenadas

[2] Endpoint valida com Pydantic

[3] Service:
    - Busca subestação no BD (SELECT)
    - Calcula BBox (math)
    - Monta URLs (3 plataformas)
    - Retorna JSON

[4] Cliente recebe JSON com:
    - Informações da subestação
    - BBox calculada
    - URLs para 3 sensores (Sentinel, Landsat, INPE)
    - Dimensões em km

[5] Cliente pode:
    - Consumir URLs (GET/POST)
    - Registrar imagens encontradas (POST)
    - Listar histórico (GET)
```
